# Доступ к Google Таблице без браузера

Нужен отдельный сервисный аккаунт Google. Ключ GigaChat используется только для
классификации и не предоставляет доступ к Google Таблице.

## 1. Создайте проект Google Cloud

Откройте https://console.cloud.google.com/ и войдите в свой Google-аккаунт.
В верхней панели выберите существующий проект или создайте новый, например
`news-classifier`. Дальнейшие действия выполняйте в выбранном проекте.

## 2. Включите Google Sheets API

Откройте https://console.cloud.google.com/apis/library/sheets.googleapis.com
и нажмите **Enable / Включить**. Google Drive API для этого скрипта не требуется.

## 3. Создайте сервисный аккаунт

Откройте **IAM & Admin → Service Accounts / IAM и администрирование → Сервисные аккаунты**:
https://console.cloud.google.com/iam-admin/serviceaccounts

Нажмите **Create service account / Создать сервисный аккаунт**, задайте имя,
например `news-classifier`, и завершите создание. Выдавать роли на весь
Cloud-проект этому аккаунту для нашей задачи не нужно: доступ к документу
будет предоставлен отдельно на шаге 5.

Скопируйте адрес созданного аккаунта, например:
`news-classifier@имя-проекта.iam.gserviceaccount.com`.

## 4. Скачайте JSON-ключ

Откройте созданный сервисный аккаунт → **Keys / Ключи** →
**Add key / Добавить ключ** → **Create new key / Создать новый ключ** → **JSON**.

Переместите скачанный файл в папку `Фильтр_новостей` и переименуйте:

```text
google_credentials.json
```

Файл должен находиться рядом с `main.py`, `api_key.txt` и `table.txt`.
Это отдельный файл: `api_key.txt` менять не нужно.
Содержимое JSON не нужно вставлять в код или отправлять в чат.
Стандартное имя уже добавлено в `.gitignore`.

Если в организации запрещено создание ключей сервисных аккаунтов, этот шаг
будет недоступен. В таком случае потребуется согласованный с администратором
способ доступа, например OAuth пользователя; обходить запрет не нужно.

## 5. Предоставьте доступ к таблице

Откройте свою таблицу по ссылке из локального `table.txt`.

В **Настройках доступа / Share** добавьте адрес сервисного аккаунта со шага 3
и выберите роль **Редактор / Editor**. Сохраните изменение доступа.
Это не адрес вашего обычного Google-аккаунта, а адрес, заканчивающийся на
`iam.gserviceaccount.com`.

## 6. Проверьте подключение

Сначала выполните установку по [README](README.md#установка-и-первоначальная-настройка).
В терминале, находясь в папке фильтра, активируйте его окружение:

```bash
source .venv/bin/activate
python main.py --check-sheet
```

Команда проверяет чтение листа «Новости» и его заголовков. Она не вызывает
GigaChat, не удаляет строки и не открывает браузер. Возможность удаления зависит
от выданной роли **Редактор**; проверка чтения сама по себе её не доказывает.

## 7. Запустите классификацию

Проверка десяти нижних новостей выбранного периода без изменений таблицы:

```bash
python main.py --from-date 2026-09-01 --to-date 2026-09-09 --dry-run --limit 10
```

Обработка с очисткой смайликов в M и удалением пустых и неполезных строк:

```bash
python main.py --from-date 2026-09-01 --to-date 2026-09-09
```

Даты относятся к **дате сбора в B**, обе границы включительно. Вывод остаётся
в терминале, журнал решений сохраняется в `.data/`. При обычных запусках
браузер, профиль Chrome и интерактивный вход в Google не используются.

При другом расположении ключа укажите `--google-credentials /путь/к/ключу.json`.
Зависимости устанавливаются из `requirements.txt` в отдельное окружение `.venv`.
Google-ключ каждого пользователя хранится локально и не входит в репозиторий.

Официальные инструкции:
- https://developers.google.com/workspace/guides/create-credentials
- https://developers.google.com/workspace/sheets/api/samples/rowcolumn
