## Требования к структуре

Названия листов: `Новости`, `Источники`, `Справочники`. Классификатор не создаёт
их и не восстанавливает выпадающие списки автоматически.

В `Новости` строка 5 должна содержать следующие заголовки A:R в точном порядке:

| Столбец | Заголовок |
|---|---|
| A | Сборщик |
| B | Дата сбора |
| C | Основной муниципалитет |
| D | Дополнительные муниципалитеты |
| E | Дата публикации |
| F | Дата события |
| G | Источник |
| H | Прямая ссылка |
| I | Дополнительные ссылки |
| J | Заголовок |
| K | Категория |
| L | Стадия события |
| M | Краткое фактическое резюме |
| N | Ключевые цифры и факты |
| O | Упомянутые лица |
| P | Организации |
| Q | ИНН из источника |
| R | Объект/населённый пункт |

B читается как `ДД.ММ.ГГГГ` или `YYYY-MM-DD`. Текст новости должен находиться
в M, несмотря на название заголовка. Столбцы после R не используются.

В `Источники` C5:H5: `Муниципалитет`, `Орган/владелец`, `Тип источника`,
`Платформа`, `Название`, `Основная ссылка`. Источники начинаются со строки 6.
Доступность или активность источника не влияет на классификацию уже собранной новости.

В `Справочники` A3:D3: `Муниципалитеты`, `Категории`, `Платформы`, `Стадии`.
Значения начинаются со строки 4. Проверенная конфигурация:

- муниципалитеты — A4:A24;
- категории — B4:B18;
- стадии — D4:D14, включая `Другое`.

Для K6:K… настройте проверку данных «список из диапазона»
`='Справочники'!$B$4:$B$18`, для L6:L… — `='Справочники'!$D$4:$D$14`.
Примените правила ко всем строкам новостей, разрешив выбор из списка и отклонение
недопустимых значений. K6/L6 используются для чтения справочников, а перед записью
проверяются правила конкретной целевой ячейки. После расширения справочника
обновите и соответствующий диапазон в правилах. Существующие значения не очищайте.

Поддерживаются `ONE_OF_LIST` и `ONE_OF_RANGE` с ограниченным одноколоночным
диапазоном. Иные правила для заполняемых полей приводят к остановке; для даты F
также поддерживается `DATE_IS_VALID`. Справочники при запуске могут отличаться
от снимка выше, но должны содержать муниципалитет `Республика Коми` и категорию
`Другое`; стадия `Другое` нужна для подстановки при неопределённости.
