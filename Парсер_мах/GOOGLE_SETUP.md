# Google Sheets API для парсера MAX

Парсер читает и записывает таблицу через сервисный аккаунт Google. Google-вход
в браузере и публичный доступ по ссылке не нужны. Авторизация MAX остаётся
отдельной и хранится в `.data/max-profile`.

## Если сервисный аккаунт уже настроен для фильтра

Можно использовать тот же сервисный аккаунт с правами редактора этой таблицы.
Поместите его JSON-ключ в `google_credentials.json` рядом с `main.py`, либо
передайте путь явно:

```bash
python main.py --google-credentials '/путь/к/google_credentials.json' --check-sheet
```

Путь можно указывать при любом запуске. На другом компьютере ключ нужно настроить
отдельно; он не включается в GitHub. Не переносите браузерный профиль чужого MAX.

## Настройка с нуля

1. Создайте или выберите проект в [Google Cloud Console](https://console.cloud.google.com/).
2. Включите [Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com).
3. В разделе **IAM & Admin → Service Accounts** создайте сервисный аккаунт.
   Для доступа к одной таблице роли на весь Cloud-проект не требуются.
4. В разделе аккаунта **Keys → Add key → Create new key → JSON** создайте ключ.
   Сохраните как `google_credentials.json` рядом с `main.py`. Если организация
   запрещает создание ключей, потребуется согласованный с администратором способ
   авторизации; текущая версия парсера поддерживает JSON-ключ сервисного аккаунта.
5. В настройках доступа Google-таблицы добавьте адрес сервисного аккаунта
   (поле `client_email` в ключе) с ролью **Редактор**. Это отдельный адрес вида
   `name@project.iam.gserviceaccount.com`, а не ваш обычный Google-аккаунт.
6. Укажите ссылку на таблицу в `table.txt` (образец — `table.example.txt`).
7. Установите зависимости и проверьте доступ:

```bash
.env/bin/python -m pip install -r requirements.txt
.env/bin/python main.py --check-sheet
```

Проверка читает структуру и новости, загружает источники, но не запускает MAX
и не изменяет ячейки. Она подтверждает чтение; для записи нужна роль редактора
и отсутствие запрета на целевые ячейки.

Обычный запуск:

```bash
.env/bin/python main.py
```

Если ключ отсутствует или Google API недоступен, запуск останавливается до MAX.
Автоматического перехода на браузерную запись или публичный CSV нет.

## Ошибки

- **401:** проверьте действительность ключа сервисного аккаунта.
- **403:** проверьте включение Sheets API, права редактора и защиту диапазонов.
- **404:** проверьте ссылку таблицы и предоставленный сервисному аккаунту доступ.
- **429:** исчерпана квота API; повторите запуск позже.

Между HTTP-запросами выдерживается интервал не менее 1,1 секунды.
После неоднозначного сбоя записи повторите тот же период: программа сначала
перечитает таблицу, поэтому подтверждённые ранее новости не добавятся повторно.
